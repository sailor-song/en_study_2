# English Study Assistant

一个简洁的英语阅读学习 Web 应用，帮助你通过阅读英文文章来积累词汇。

## 快速开始

### 1. 启动服务

```bash
python server.py
```

然后访问 http://localhost:8080

### 2. 添加文章

将 `.md` 格式的英文文章放入 `articles/` 文件夹，支持的元信息：
- 标题（文件首行 `#` 后的文本）
- 单词数量（自动统计）

## 功能模块

### 首页 (Home)
- 文章卡片展示，显示标题、阅读时长、单词数
- 点击卡片直接进入阅读页

### 阅读页 (Reading)
- 渲染 Markdown 格式的文章内容
- **词汇高亮**：单词本中已收藏的词汇会高亮显示
- **词汇注释**：点击高亮词汇查看释义和掌握程度
- **划词助手**：选中文中任意单词/词组，添加至单词本

### 单词本 (Vocabulary)
- 集中管理已收藏的词汇
- 查看释义、例句、掌握程度
- 支持搜索、编辑、删除
- 导出功能：可将单词本导出为 txt 文件备份
- 清除功能：一键清空所有词汇

### 测试 (Quiz)
- 拼写测验：根据中文释义拼写英文单词
- 支持选择测验数量（全量/10/20/50）
- 答题结果自动更新词汇掌握程度

## 数据存储

- **单词本**：浏览器 localStorage，重启浏览器不丢失
- **文章**：本地 `.md` 文件，由服务器动态读取

## 技术栈

- 前端：原生 HTML + Tailwind CSS + Vanilla JS
- 后端：Python HTTP Server
- Markdown 解析：marked.js
